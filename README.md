## 🚀 Projects

### Task 2 – Online Banking System

A Python-based desktop banking application developed using Tkinter and SQLite.

**Features:**
- User registration and login authentication
- Password hashing
- Automatic account number generation
- Balance enquiry
- Deposit and withdrawal operations
- Insufficient balance validation
- Transaction history
- Logout functionality

**Technologies:** Python, Tkinter, SQLite

**Project Folder:** `Task2_OnlineBanking/`

[View Online Banking System](./Task2_OnlineBanking/)

### Task 4 – Aparna AI Voice Assistant

A Python-based voice assistant with a modern graphical interface. It recognizes voice commands and responds using speech.

**Features:**
- Speech recognition
- Text-to-speech responses
- Modern CustomTkinter interface
- Animated microphone button
- Separate user and assistant chat bubbles
- Voice selection
- Weather information
- Google search
- Wikipedia information
- Open YouTube and Google
- Launch Notepad and Calculator
- Random jokes
- Clear conversation option

**Technologies:** Python, CustomTkinter, SpeechRecognition, PyAudio, pyttsx3, Wikipedia, PyWhatKit, Requests and PyJokes.

**Project Folder:** `Task4_VoiceAssistant/`

[View Aparna AI Voice Assistant](./Task4_VoiceAssistant/)
