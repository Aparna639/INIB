# Online Banking System

## Project Overview
The Online Banking System is a Python-based desktop application developed as part of the InfoByte Python Internship.

It provides basic banking operations through a graphical user interface (GUI), allowing users to create accounts, log in securely, deposit money, withdraw money, and view transaction history.

## Features
- User Registration
- User Login and Authentication
- Password Hashing
- Account Number Generation
- Balance Enquiry
- Deposit Money
- Withdraw Money
- Insufficient Balance Validation
- Transaction History
- Logout Functionality

## Technologies Used
- Python
- Tkinter – Graphical User Interface
- SQLite – Database Management
- hashlib – Password Hashing

## How to Run the Project

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python Task2_OnlineBanking/main.py
```
